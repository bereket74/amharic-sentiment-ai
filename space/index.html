Browser-only · Amharic · Three classes

Amharic Sentiment AI

Classify a short Amharic message as positive, neutral, or negative. The model runs on your device; your text is not sent to an inference server.

Longer messages are truncated to the model's 72-token input limit.

On first use, the browser downloads about 141 MB of model and tokenizer files. The browser may cache them for later use.
Predicted sentiment

Limits and privacy: This is an 8-bit, quantized version of the published transformer. It is close to, but not identical to, the full model. Scores are not calibrated probabilities; do not use predictions for high-impact decisions or profiling. The browser downloads public model files from Hugging Face; the text you enter is processed locally and is not uploaded by this page. Browser memory and speed vary by device.
